# K. Hari Shankar Portfolio

A cinematic, dark-themed portfolio website for K. Hari Shankar, highlighting 3D environment art, VR development, Unity projects, AI/ML work, and immersive interactive systems.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the site.

## Production build

```bash
npm run build
```

The app is configured to be deployable directly to Vercel.
